# authenticate

## 📌 一言でいうと

**今回のコードでは、受け取ったパスワードを渡して認証処理を呼び出すメソッド。**

**分類：認証関連。Model・Controllerのどちらに属するかは、メソッドの定義を確認する必要がある。**

## 📖 仕組み・役割

```ruby
authenticate(params[:password])
```

このコードは、次の２つに分けて読むと理解しやすくなります。

|コード|意味|
|---|---|
|`params[:password]`|受け取ったデータから、`password` の値を取り出す|
|`authenticate(...)`|取り出した値を引数として渡し、メソッドを呼び出す|

**「パスワードを取り出す → 認証処理に渡す」**という流れです。


## 💻 コード例

```ruby
authenticate(params[:password])
```

２行に分けると、次のように読めます。

```ruby
password = params[:password]
authenticate(password)
```

どちらも、取り出したパスワードを `authenticate` に渡しています。


## 🎯 使用場面

パスワードを使った本人確認などの場面。

カリキュラムで具体的に何を認証しているかは、前後のコードや定義を確認します。


## ⚠️ 注意点・よくある間違い

**① `params[:password]` がパスワードを確認するわけではない**

ここでは値を取り出しているだけです。認証処理は `authenticate` 側で行います。

**② 戻り値は、この一行だけでは分からない**

成功時に何が返るか、失敗時に何が返るかは、メソッドの定義によって異なります。

**③ これだけでログイン完了とは限らない**

ログイン状態を保存する処理まで含むかどうかも、定義次第です。
