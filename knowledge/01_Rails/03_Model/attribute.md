# attribute

## 📌 一言でいうと

**モデルの属性に、データの型や初期値を設定するRailsのメソッド**

属性とは、`name`や`age`のような「オブジェクトが持つデータ項目」のこと

## 📖 仕組み・役割

基本の書き方は次のとおり

```ruby
attribute :属性名, :型, default: 初期値
```

たとえば、次のコードは「年齢を整数として扱い、指定がなければ初期値を0にする」という設定

```ruby
attribute :age, :integer, default: 0
```

|部分|意味|
|---|---|
|`:age`|属性の名前|
|`:integer`|整数として扱う指定|
|`default: 0`|値を指定しなかったときの初期値|

`attribute`では、既存の属性の型や初期値を設定できるほか、**データベースにカラムがない属性も定義できる**

## 💻 コード例

```ruby
# app/models/user.rb
class User < ApplicationRecord
  attribute :age, :integer, default: 0
end
```

```
user = User.new

# 値を指定していないため、初期値は0
user.age
# => 0

# 文字列の"25"を代入
user.age = "25"

# 読み取ると整数の25になる
user.age
# => 25
```

`"25"`は文字列、`25`は整数

`:integer`を指定しているため、代入した値を整数に変換して扱える


## 🎯 使用場面

- 属性に初期値を設定したいとき
- 入力された文字列を、整数などの型に変換して扱いたいとき
- データベースに保存しない一時的な属性をモデルに持たせたいとき


## ⚠️ 注意点・よくある間違い

**① `attribute`を書いても、データベースにカラムは追加されない**

カラムを追加するには、マイグレーションが必要

上の例でも、`users`テーブルに`age`カラムがなければ、`age`の値は通常の`save`では保存されない

**② すべてのカラムに書く必要はない**

Active Recordは、データベースのカラムから属性や型を自動で読み取る

型や初期値を明示的に設定したい場合などに使う

**③ 型の変換と入力チェックは別の役割**

`attribute`は型などの設定、`validates`は値がルールを満たすかの確認

`:integer`を指定するだけで、不正な入力をすべてエラーにできるわけではない

## 🔄 復習メモ

### Q1. `attribute`は何をするメソッド？

モデルの属性に、型や初期値などを設定するメソッド

### Q2. `attribute`はどこに書く？

基本的にモデルのクラス内に書く

### Q3. `default: 0`はどういう意味？

値を指定しなかったときに、初期値として0を使うという意味

### Q4. `attribute`を書けばデータベースにも保存される？

書くだけでは保存先は作られない

通常の`save`で保存するには、対応するカラムが必要
