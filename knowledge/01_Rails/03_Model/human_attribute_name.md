# human_attribute_name

## 📌 一言でいうと

**モデルの属性名を、翻訳設定に応じた表示名に変換するメソッド**

## 📖 仕組み・役割

```ruby
User.human_attribute_name(:id)
```

それぞれの意味は次のとおり

|部分|意味|
|---|---|
|`User`|表示名を調べる対象のモデル|
|`human_attribute_name`|属性名に対応する、人向けの表示名を取得するメソッド|
|`:id`|表示名を取得したい属性|

日本語の翻訳設定があれば、その内容を表示に使う

**このコードだけでは、実際に表示される文字までは確定できない**

## 💻 コード例

たとえば、日本語の翻訳ファイルに次の設定がある場合

```ruby
# config/locales/ja.yml
ja:
  activerecord:
    attributes:
      user:
        id: ユーザーID
```

日本語ロケールで次のコードを実行すると、`"ユーザーID"`を取得できる

```ruby
User.human_attribute_name(:id)
# => "ユーザーID"
```

ビューでは、その表示名を表の見出しに埋め込む

```ruby
<th scope="col"><%= User.human_attribute_name(:id) %></th>
```

出力されるHTML

```ruby
<th scope="col">ユーザーID</th>
```

|記述|役割|
|---|---|
|`<th>`|表の見出しセルを作る|
|`scope="col"`|その列の見出しであることを示す|
|`<%= ... %>`|Rubyコードの実行結果をHTMLに出力する|


## 🎯 使用場面

- 一覧画面の見出しに、モデルの属性の表示名を使いたいとき
- 項目名を翻訳ファイルでまとめて管理したいとき
- 日本語や英語など、言語に応じて項目名を切り替えたいとき

## ⚠️ 注意点・よくある間違い

**① `attribute`とは別のメソッド**

|メソッド|役割|
|---|---|
|`attribute`|属性の型や初期値などを設定する|
|`human_attribute_name`|属性の表示名を取得する|

**② ユーザーのIDの値を取得するコードではない**

```ruby
user.id
# 特定のユーザーのIDの値を取得
# 例：1
```

```ruby
User.human_attribute_name(:id)
# idという項目の表示名を取得
# 例："ユーザーID"
```

**③ 日本語を自動翻訳してくれるわけではない**

日本語表示には、翻訳設定と日本語ロケールの設定が必要

翻訳が見つからない場合は、属性名を人向けに整えた文字列などにフォールバックする

## 🔄 復習メモ

### Q1. `User.human_attribute_name(:id)`は何を取得する？

Userモデルの`id`という属性の表示名

### Q2. `user.id`との違いは？

`user.id`は実際の値、`User.human_attribute_name(:id)`は項目の表示名を取得する

### Q3. 表示名を「ユーザーID」にしたい場合は？

日本語の翻訳ファイルで`activerecord.attributes.user.id`に「ユーザーID」を設定し、日本語ロケールで表示する
