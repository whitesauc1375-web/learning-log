# Turbo系

## 📌 一言でいうと

**avaScriptをたくさん書かなくても、ページの移動や部分更新を実現できる仕組み。**

**分類：主にView（ビュー）。Controllerとも連携する。**


## 📖 仕組み・役割

Turboには、主に３つの機能があります。

|機能|役割|使用例|
|---|---|---|
|**Turbo Drive**|リンクやフォーム送信を処理し、ページ全体の再読み込みを避けて画面を切り替える|ページ移動|
|**Turbo Frames**|指定した枠の中だけを更新する|一覧内で編集フォームを表示|
|**Turbo Streams**|HTMLの指示に従って、要素の追加・更新・削除などを行う|投稿したコメントを一覧へ追加|


## 💻 コード例

カリキュラムで見かけやすいのは、次のような書き方です。

```
<%= link_to "ログアウト", logout_path,
    data: { turbo_method: :delete } %>
```

|コード|意味|
|---|---|
|`link_to`|リンクを作る|
|`logout_path`|リクエストの送信先|
|`turbo_method: :delete`|TurboにDELETEリクエストを送るよう指定する|

通常、リンクは **GET（ページの取得）** に使います。この例では、Turboによって **DELETE** のリクエストを送ります。

**`turbo_method` はRubyのメソッドではなく、Turboに送信方法を伝えるための指定です。**


## 🎯 使用場面

- リンクからDELETEリクエストを送る
- ページの一部分だけを更新する
- コメントを画面全体の再読み込みなしで追加する

## ⚠️ 注意点・よくある間違い

**① Turboと`turbo_method`は別**

- **Turbo**：画面の移動や更新を支える仕組み
- **`turbo_method`**：リンクで使うHTTPメソッドの指定

**② `:delete`を書くだけでデータが削除されるわけではない**

DELETEリクエストを送る指定です。実際の処理は、ルーティングで呼び出されたControllerが担当します。

**③ Turboが動作している必要がある**

`turbo_method` の指定は、TurboのJavaScriptが読み込まれていることを前提とします。

## 🔄 復習メモ

### Q1. Turboは１つのメソッド？

違う。ページ移動や部分更新を実現する仕組み。

### Q2. `turbo_method: :delete`は何をする？

リンクからDELETEリクエストを送るよう、Turboに指示する。

### Q3. DELETEリクエストを送れば、必ずデータが削除される？

削除されるとは限らない。実際に何をするかは、呼び出されたControllerの処理による。
