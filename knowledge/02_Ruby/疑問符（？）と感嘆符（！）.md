# 疑問符（？）と感嘆符（！）

## 📌 一言でいうと

Rubyではメソッド名の末尾に `?` や `!` を付ける命名規則がある。

- `?`：条件を確認するメソッドでよく使う
- `!`：注意が必要な動作をするメソッドでよく使う

## 📖 仕組み・役割

- [[nil?・empty?・blank?・present?]]
- [[valid?]]
- [[persisted?]]
- [[include?]]

### `!` の代表例

- [[save・save!]    
- [[create・create!]]
- [[update・update!]]
- [[destroy・destroy!]]



## 💻 コード例

```ruby
"Ruby".present?
# => true

user.save
# 保存失敗時は通常falseを返す

user.save!
# バリデーション失敗時は例外を発生させる
```


## 🎯 使用場面

- データの有無を確認するとき
- 条件によって処理を分岐させるとき
- 保存・更新などの失敗を例外として扱いたいとき


## ⚠️ 注意点・よくある間違い

`?` と `!` はメソッド名の一部であり、付けるだけで動作が自動的に変わるわけではない。
