## 今日理解できたこと
- resources メソッド

`resources :users`と書くと、RailsがCRUD用のルートを作ってくれる

    - index
    - show
    - new
    - create
    - edit
    - update
    - destroy

- link_toメソッド

リンクを作成するためのヘルパーメソッド、HTMLのaタグの代わりに使用可能

最も一般的な使用例は、リンクのテキストとリンク先のパスを指定させる

- if logged_in?メソッド

ユーザーがログインしているかどうか（真偽値）を判定するヘルパーメソッド

- レイアウトの中に `<%= yield %>` と書くと、コントローラが`render`した内容がそこに埋め込むことができる

- `t('.title')`. から始めると『現在のViewの場所を基準にして翻訳を探す』という書き方ができる！

## まだ理解できていないところ
- status: :see_other

Railsでリダイレクトするときに使うHTTPステータスコード「303 See Other」**を指定する書き方

`status: :see_other`を指定しない場合はリダイレクト後もブラウザがPOSTメソッドを保持し続け、予期せぬ挙動に繋がる恐れあり…

- form_withメソッド

フォームを実装するためのヘルパーメソッド、パスの指定やRubyの埋め込みなどの記述がシンプルになるメリットがある

- turbo_method

Turboを使用してHTTPリクエストを送信する際に、使いたいHTTPメソッドを指定するための機能

Railsのビューで使うと、特定のアクションを実行するために便利
