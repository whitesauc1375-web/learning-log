- **RubocopとRSpecの違い**
	- RuboCop：書き方のルール違反や、バグにつながりそうな記述を見つける
	- RSpec：アプリが仕様どおりに動くか確認する
- `rails g model`と`rails g migration`の違い復習
- gitコマンドの復習
- `do ... end` は処理のまとまり（ブロック）を表し、`do` 自体に「繰り返す」という意味はない
>`each do`の『 do 』は繰り返しという意味ではない！
- `data-turbo-track="reload"` ：Turbo に再読み込みの条件を伝える HTML 
>Turbo でページを移動するとき、指定した CSS や JavaScript の読み込みタグに変更があれば、ページ全体を再読み込みする。これにより、更新されたファイルを読み込み直せる
