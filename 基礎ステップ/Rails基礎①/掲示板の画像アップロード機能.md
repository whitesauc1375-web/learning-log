
- extension_allowlist メソッド
CarrierWaveで**アップロードを許可するファイルの拡張子**を指定するためのメソッド（jpg・jpeg・gif・pngなどを許可）
```ruby
def exetention_allowlist
	%w[jpg jpeg gif png]
end
```
これは「画像をアップロードするとき、jpg・jpeg・gif・pngだけ受け付けてください」と、CarrierWaveにルールを教えてている。


-  default_url メソッド
CarrierWaveで画像がまだアップロードされていないときに、**代わりに表示する画像やURLを指定するため**のメソッド
```ruby
def default_url
	'board_placeholder'
end
```
掲示板画像がまだ登録されていない場合は、`board_placeholder` をデフォルト画像として使うという設定。


- acceptオプション
ファイル選択画面で「どんな種類のファイルを選べるようにするか」をブラウザに伝えるための指定
今回のコードだと、こうなっている
```ruby
<%=f.label:board_image,class:"form-control",accept:'image/*'%>
```

`accept:'image/*`　この部分が`acceptオプション`
**このファイル選択欄では、画像ファイルを選ぶ用途ですよ**とブラウザに伝える、ということjpg・jpeg・gif・pngなど）

-  hidden_field
画面には表示しないけれど、フォーム送信時には値を一緒に送るための入力欄
今回の課題では、
```ruby
<%= f.hidden_field :board_image_cache %>
```
これは、`board_image_cache` という値を、ユーザーには見せずにフォームの中に保持しておくという意味
今回 `board_image_cache` で使う理由は、**フォーム送信に失敗したときでも、一度選んだ画像情報を保持するため**
