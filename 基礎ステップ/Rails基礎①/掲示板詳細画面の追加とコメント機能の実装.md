
# own?メソッド
```ruby
def own?(object)
  id == object&.user_id
end
```
`own?` は

```このデータは自分のものか```

を判定するために作成したメソッドとなる

## ?で終わるメソッド
Rubyでは
`own?`
のように `?` で終わる名前を、真偽値を返すメソッドに使用することが多い

真偽値とはこの2種類を指す
- true
- false

# `l` メソッド

```ruby
<%= l @board.created_at, format: :long %>
```

`l` はlocalizeの略で、**日時を指定した形式で表示するために使用するRailsのI18n用メソッド**となる
`@board.created_at
は掲示板が作成された日時を指す

`format: :long
は日時を `long` 形式で表示する指定となる

# simple_format

```ruby
<%= simple_format(@board.body) %>
```
`simple_format` は**文字列内の改行などをHTMLに反映しやすい形へ変換するRailsのヘルパーメソッド**となる

例えば投稿内容が、以下のように改行されている場合、その改行を画面上でも表示しやすくできる
- 今日はRailsを勉強した
- ルーティングを覚えた
